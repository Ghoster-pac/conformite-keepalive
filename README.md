# conformite-keepalive

Petit dépôt **public** dont l'unique rôle est de garder éveillée l'application
Render gratuite « Contrôle de conformité » :

👉 https://conformite-pfgh.onrender.com

Un **GitHub Action** visite le site toutes les 5 minutes. Sur un dépôt public,
les minutes Actions sont **gratuites et illimitées** — aucune carte n'est requise.
Cela évite le délai de réveil (~30-60 s) de l'offre gratuite de Render.

Aucun secret, aucune donnée n'est stockée ici.
